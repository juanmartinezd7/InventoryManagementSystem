# Overview

The Inventory Management System is a console-based application developed in C# that allows users to manage product information and track inventory levels. The software provides features for adding, updating, deleting, and searching products, as well as adjusting stock quantities, identifying low-stock products, calculating total inventory value, and viewing stock transaction history.

I developed this software to strengthen my skills as a software engineer by gaining hands-on experience with C# programming fundamentals, object-oriented programming, data structures, input validation, and file management. My goal was to build a practical application that demonstrates how these concepts work together to solve a real-world inventory management problem.

The application uses JSON file storage to preserve product information between sessions. Stock transaction history is recorded during the current session.

# Development Environment

I developed this software using Visual Studio Code as my code editor, the .NET 10 SDK to build and run the application, and Git and GitHub for version control and source code management.

The programming language used is **C#**, a modern, object-oriented language developed by Microsoft. The application uses classes to represent products and manage data storage, a structure to represent inventory transactions, and collections to manage products and stock movements. It also demonstrates conditional statements, loops, methods, arithmetic expressions, and input validation.

For data persistence, I used the built-in `System.Text.Json` library to serialize and deserialize product information, allowing the application to read and write inventory data in JSON format.
